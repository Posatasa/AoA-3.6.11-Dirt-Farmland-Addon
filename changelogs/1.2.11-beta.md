# 1.2.11-beta

The petal crafting station now also pays out copper coins for AoA crops, the way AoA's own
mineralization station does for ores.

Right-click the station holding any of AoA's crops and one is consumed for a handful of
`aoa3:copper_coin`. The payout is the mineralization station's own formula - `base + random(base)`
coins - which is exactly what the ranges below work out to, so each crop only needs its base:

| crop | coins | crop | coins |
| --- | --- | --- | --- |
| `tea_shreddings` | 2-3 | `rosidons` | 5-9 |
| `heart_fruit` | 3-5 | `thorny_petals` | 3-5 |
| `bubble_berries` | 7-13 | `trilliad_leaves` | 11-21 |
| `chilli` | 5-9 | `eye_bulb` | 5-9 |
| `floracle_sticks` | 5-9 | `mystic_shrooms` | 5-9 |
| `goldicap_petals` | 5-9 | `magic_marang` | 7-13 |
| `luna_globe`, `lunacrike`, `lunalons` | 7-13 | | |

Creative mode does not consume the crop, matching both AoA's station and this add-on's moon soil
ritual. The coins go into the inventory, or drop at the player's feet if it is full.

The two station rituals now share their sound and particle helper, so the station's own use sound is
resolved in one place instead of two. All sixteen AoA names involved are checked against the AoA jar
at build time, alongside the existing fifty.
