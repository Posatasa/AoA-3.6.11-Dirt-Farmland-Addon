# 1.2.5-beta

Trampling a farmland in an AoA dimension sometimes left vanilla dirt behind instead of the AoA soil.

`fallOn` called the superclass implementation after doing its own conversion, and
`FarmlandBlock#fallOn` runs the same trample test again and turns whatever is there into
`minecraft:dirt`. Because `Entity#canTrample` rolls a random number, the two calls sampled
independently: the block could end up as the AoA soil or as vanilla dirt depending on two coin
flips. The override no longer chains to it.

The same audit found a second hole: `getStateForPlacement` inherits vanilla's answer, which is
"dirt" when the spot cannot hold farmland, so placing one of these blocks under a solid block or on
something that is not soil produced vanilla dirt too. It now answers the matching AoA soil.

The build check grew to cover all four vanilla paths and to reject any override that calls the
superclass version - both mutations were used to confirm it refuses.
