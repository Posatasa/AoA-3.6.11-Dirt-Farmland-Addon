# 1.0.4-alpha

Fixed a server crash when bone-mealing a melon/pumpkin stem on this farmland (NoSuchFieldError:
MOISTURE). isFertile reads the inherited FarmlandBlock.MOISTURE constant, which compiles to a
reference whose owner is *our* class; the remapper only walked the hierarchy of Minecraft classes,
so it never resolved it. Inherited members now resolve through our classes' own supertypes too, and
the reference check no longer skips references that point at our own classes - which is exactly how
this one escaped.
