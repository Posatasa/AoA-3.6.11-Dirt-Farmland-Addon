# 1.2.9-beta

Two clean-ups so that Farmer's Delight really is only an *interaction*: with it absent, nothing that
was added for it appears.

Colonies now survive on the two AoA soils through a hook on Farmer's Delight's own colony block
instead of through vanilla's `minecraft:mushroom_grow_block` tag. Vanilla reads that tag to decide
where giant mushrooms may grow, so having the soils in it meant giant mushrooms appeared on them
even without Farmer's Delight - and, worse, the tag file was still being shipped after 1.2.8
dropped it, because the generator never cleaned the data directories.

The build now checks all three ways that optionality can leak: a linked Farmer's Delight class, a
dependency entry in mods.toml, and a vanilla tag file that vanilla itself reads.
