# 1.0.3-alpha

Fixed a crash when opening the creative inventory. The creative tab's makeIcon override had been
left with its MCP name by the build's remapper, so the tab class still had an unimplemented abstract
method and the game died with AbstractMethodError the moment the tab was drawn. The remapper now
renames overridden members too, and two checks make that failure mode unshippable: every override
must carry its SRG name, and no concrete class may still expose an abstract method.
