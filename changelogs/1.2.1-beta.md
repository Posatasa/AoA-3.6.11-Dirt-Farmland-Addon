# 1.2.1-beta

Fixed a crash on the first harvest (`NoSuchMethodError: List.func_190926_b`). `ItemStack.isEmpty`
and `java.util.List.isEmpty` shared one constant-pool NameAndType entry in the loot modifier's class
file, so renaming the Minecraft one also renamed the JDK one. References that need renaming now get
their own entry, and the build rejects any library member left with an SRG name - the check was
verified by reproducing the crash's bytecode.
