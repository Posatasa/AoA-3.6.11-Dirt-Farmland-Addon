# 1.2.0-beta

Fertilised farmland for every soil, wired into AoA's farming system: bone meal through AoA's
*Fertilise Farmland* ability, the green manure crop that sets `well_fertilised`, and an equivalent
harvest modifier so a mature crop gives its +1/+2 bonus and steps the block back down toward plain
farmland. AoA's ability and crop are hooked by mixin *name* (string targets, `require = 0`,
`required: false`), so the build still links against no AoA type at all.
