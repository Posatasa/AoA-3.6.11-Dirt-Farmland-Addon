# 1.1.0-alpha

Each farmland now has eight top textures, one per moisture level, so it visibly dries out and wets
up step by step instead of flipping between two looks at level 7. Purely asset-side change. The
build also gained a resource check: every blockstate, model parent, texture and translation key must
resolve, for both its own namespace and (when an AoA jar is present) AoA's.
